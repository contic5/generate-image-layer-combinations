# Generate Image Layer Combinations
## About
This project generates combinations of images. The program reads two folders, "front_images" and "back_images." The program makes an image for each combination of front image and back image, where the front image is layered onto the back image.

This project also generates a merged image, which takes every single combination and places them in one image by using a grid. The program also shows which front image and which back image resulted in each combination. The row corresponds to the back image and the column corresponds to the front image.
